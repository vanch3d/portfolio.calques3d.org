A short contract, a blank OpenAPI spec, and a legacy PHP backend with no documentation. The
brief was to build a functional Angular admin interface in six weeks. The interesting part was
not the UI itself — it was what had to happen before any UI could be designed at all.

The first two weeks were spent reading HTTP traffic and writing the OpenAPI spec from scratch,
working backward from observed request/response pairs. The spec became the contract that the
Angular layer was built against, and the only thing that made it possible to reason about the
backend without access to its source code.

<Aside>
  OpenAPI as reverse-engineered documentation: when the backend has no spec, writing one
  from traffic observation is still worth doing — it becomes the shared language between
  the frontend and whatever comes after the contract ends.
</Aside>

The result was a working admin panel and a spec that outlasted the contract — handed over as
the closest thing to documentation the codebase had.
