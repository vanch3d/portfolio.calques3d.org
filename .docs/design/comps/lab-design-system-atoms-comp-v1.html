Atom

Button

Three named variants, matching the TagFilterDrawer NONE/CLOSE precedent, named properly this time. Plain <button> — no hidden state machine, so no Base UI wrapper needed. Hover/focus/active below are real; Tab to any button to see the global ring.

Primary — rest / hover / active Solid ink fill. One per view — the assertive commit action.
Primary — disabled ink-ghost border/text — needs axe-exception comment per accessibility.md.
Secondary — rest / hover / active border-medium ink-secondary at rest — never ghost. Supporting action.
Secondary — disabled
Text-action — rest / hover / active No border, ever. Matches TagFilterDrawer's NONE/CLOSE — now a named variant.
Text-action — disabled
Atom · Base UI Checkbox

Checkbox

Real hidden ARIA state machine via Base UI. Visual states map to its exposed data-checked / data-disabled attributes. Sharp square, Compass Grammar-legal.

Output types

Click to check/uncheck · hover to see border deepen · Tab to see the global focus ring · last two are disabled (unchecked and checked).

Atom · Base UI Radio / RadioGroup

Radio / RadioGroup

Replaces TagFilterDrawer's disabled-looking view-mode tabs with a real, accessible RadioGroup — same three options ("By frequency" is live today; category/status are the announced growth path), now with genuine selected/focus/disabled states instead of opacity-40 text. Circular geometry — resolved, reversing the earlier square decision: a circular dot reads correctly as a radio control in practice, where a square doesn't, despite square being the philosophically consistent Compass Grammar reading. This is the one place a small circular mark appears outside the hero arc — see DESIGN.md's Shapes clarification.

Group tags by

Frequency is the only mode implemented today; status is present-disabled as a growth-path signal.

Atom · Base UI Field / Fieldset

Field / Fieldset

Label + description + error-message wiring around any control. Error state does not use the active red — the breadcrumb above already spends this surface's One Red Rule allowance, and validation is a different semantic from "current/selected" in any case. Error is encoded by border-weight escalation plus a glyph, never colour.
