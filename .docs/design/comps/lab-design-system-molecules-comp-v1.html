Construction Panel — new

Generalises MoleculeFrame's static border-t-heavy border-ink / border-b-medium border-ink-ghost framing into a container for an expanded, interactive region — the shape a drawer, panel, or disclosure should take once open. Border-weight escalation + tonal fill, zero shadow, per the Flat-by-Construction Rule. Governed by The Live Line Rule for its own toggle control.

Closed

No tags selected

Toggle at rest reads as a text-action link (Button atom, text-action variant) — no border, no panel rendered.

Open

High frequency

Chips reuse the Live Line Rule's corrected rest-state border (ink-secondary, never ink-ghost) — the same fix the TagFilterDrawer retrofit needs at the chip level.

  • → Top edge:border-heavy ink — opens the zone, reads as "this now belongs to the panel."
  • → Remaining edges:border-medium ink-secondary — never ink-ghost (fails 3:1 boundary contrast on cream).
  • → Fill:bg-ground-warm distinguishes the drawn zone from the page plane without a shadow.
Construction recipe
Edge / surface Token Purpose
Top border border-heavy · ink Opens the zone — heaviest line on the panel, signals "interactive region starts here."
Right / bottom / left border border-medium · ink-secondary Encloses the region at a legible, non-ghost weight.
Fill bg-ground-warm Tonal shift from the page's bg-ground — the only depth cue, per Flat-by-Construction.
Toggle control Button — text-action variant Rest/hover/active states per The Live Line Rule; no border at rest.
Contents any atom set (chips shown here) Panel is a container, not a fixed layout — content-agnostic.
