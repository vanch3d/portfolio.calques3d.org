Design System

The Construction on Tracing Paper

A geometric proof in progress — compass arcs, dimension lines, and construction marks on cream draughting paper. Every element is placed with the deliberateness of a technical drawing: no decoration that isn't also structural, no colour that isn't also information.

Named Rules

The One Red Rule

The compass-arc red appears exactly once per surface — on the single element that is active, current, or selected.

A second red on the same surface means the first was wrong. Its rarity is the point.

The No-Decoration Rule

If removing an element makes the surface less informative, it was earning its place. If it makes it calmer, it was decoration.

Every mark on the drawing earns its place or is removed.

The Flat-by-Construction Rule

No shadows. Depth from line weight and tonal ramp only — heavy lines are closer, ghost lines are background.

A shadow here would be a smudge on the drawing.

The Live Line Rule — new

Every interactive element carries exactly one line weight and one ink tone per state — rest, hover, focus, active, selected, disabled — drawn from the existing graphite ramp, never invented per component.

Rest is Faded Graphite, never Ghost Line — a resting boundary that thin reads as absent. Focus is always the single global red ring. A control's state must be legible before it is touched.

Note — One Red Rule bookkeeping

Every "— new" tag on this page (the fourth rule card, the Atoms strip subheading, the Construction Panel row) is a draft-review annotation only, not part of the shipped surface — each uses active-mark so none of them can ship as-is without becoming a second, third, or fourth red on this surface.
